Engineering Evolution & Architectural Decisions

The Build Story

How this platform evolved from initial prototypes into modular, resilient systems—driven by deliberate architectural questions, collaborative AI co-pilots, and Google Antigravity multi-agent orchestration.

1. Secret Hygiene & Clean Environment Isolation
Oct 2025 • Initial Foundation
Challenge Committing early prototypes risked leaking API credentials and triggering GitHub push protection blocks.
Decision Rewrote git history using filter-branch, enforced strict .env exclusion, and isolated keys to local and platform runtime variables.
2. Deconstructing the Monolith into Flask Blueprints
May 2026 • Architecture Migration
Challenge Single-file Flask app caused module interdependencies: an error in chess scraping crashed the entire career agent.
Decision Deconstructed monolithic Profile-Agent into modular newhome blueprints with independent route handlers, error handling, and config boundaries.
3. Privacy-by-Design: Zero Server-Side Conversation Storage
May 2026 • Agent Governance
Challenge Retaining chat conversations on a server database introduces security risks, GDPR liabilities, and cross-visitor memory leaks.
Decision Pioneered zero server-side memory: chat history lives solely in the visitor's browser memory (JavaScript) and is completely erased on refresh.
4. Ground-Truth Resume Grounding vs. LLM Hallucinations
Jul 2026 • Prompt Engineering
Challenge Frontier LLMs frequently embellish credentials, overstate certifications, and invent unverified technical claims.
Decision Implemented a rigorous document-parser pipeline feeding verified Markdown source facts directly into prompts with strict zero-hallucination boundaries.
5. Democratic Crowd Consensus vs. AI Opponent ("Guru-Bot")
Aug 2026 • Multi-Agent Experiment
Challenge Public social media commentary invites rogue moves, invalid notation, and spam in interactive games.
Decision Engineered a 3-supporter quorum consensus algorithm with python-chess FEN validation and LinkedIn comment scrapers to govern social gameplay.
6. Asynchronous Non-Blocking SMTP Dispatch
Aug 2026 • Reliability
Challenge Synchronous email handshakes caused Gunicorn worker timeouts and 502 gateway errors during traffic bursts.
Decision Offloaded notification dispatches to isolated background threads with 5-second fail-fast connection timeouts.
7. Decoupled Resilience: GitHub Pages + Microservice APIs
Nov 2026 • Zero-Cost Architecture
Challenge Tying portfolio uptime to a paid custom domain and monolithic cloud instances created recurring costs and single-point-of-failure risks.
Decision Decoupled the public presentation layer to permanent, zero-cost GitHub Pages (spmcgarry.github.io) with modular API calls to Railway microservices.
